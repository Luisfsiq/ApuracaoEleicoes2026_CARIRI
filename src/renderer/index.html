GUIA RÁPIDO

Como usar

Um fluxo simples para importar, registrar, conferir e compartilhar a apuração.

01

Importe

Use a planilha fornecida ou escolha outra cópia no mesmo formato. O aplicativo identifica as abas municipais automaticamente.

02

Registre

Em Lançamento, selecione município, local e seção. Digite os votos de cada candidato e altere o status para apurada.

03

Compare

A Visão geral recalcula os rankings. Em Votos por município, cada candidato aparece com os totais dos nove municípios.

04

Exporte

Gere uma nova planilha Excel com os lançamentos. O arquivo de origem permanece intacto.

O que cada indicador significa

% apurado
Seções marcadas como “Apurada” divididas pelo total de seções.
Percentual do candidato
Participação nos votos dos candidatos listados para o mesmo cargo.
Eleitores do local
Referência do local de votação inteiro. Não corresponde ao eleitorado de uma seção isolada.
Votos lançados
Soma dos campos de candidatos da seção, abrangendo os cinco cargos.
Boas práticas

Confira o boletim antes de marcar a seção como apurada. Exporte cópias periódicas durante a apuração para manter um histórico.
